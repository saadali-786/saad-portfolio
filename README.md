# Saad Shah — AI Systems Portfolio

A responsive portfolio for AI systems, workflow design, decision intelligence, and data exploration. Built with plain HTML, CSS, and JavaScript.

## What’s included

- Six featured projects with custom visuals
- A searchable, filterable directory of all 21 original public repositories
- Responsive layouts, accessible navigation, and reduced-motion support

## Files

- `index.html` — page content and all repository links
- `index.css` — responsive visual design and motion
- `script.js` — mobile navigation, archive filters, scroll reveals, and current year
